# AI-Powered Continuous Cyber Risk Quantification and Investment Optimization Platform

SIH26105 Project - Full Stack Prototype

## Project Description

An AI-powered platform for continuous cyber risk quantification and investment optimization. The system continuously monitors cyber risk factors, quantifies potential impacts, and provides data-driven investment optimization recommendations.

## Technology Stack

- **Backend**: Python FastAPI
- **Frontend**: React with Vite
- **Database**: SQLite
- **ML/Math**: NumPy, pandas
- **Containerization**: Docker (optional)
